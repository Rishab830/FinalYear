TITLE: A Smart System for Early Detection and Prevention of Forest Fire using UAV Swarms and VLM

AUTHORS: Sarah Basahel, Adnan Ahmed Abi Sen, Nour Mahmoud Bahbouh, Omar Tayan, Adel Ben Mnaouer, Mohammad Yamin
INSTITUTIONS: King Abdulaziz University (Saudi Arabia), University of Prince Mugrin (Saudi Arabia), Granada University (Spain)
PUBLICATION: 2025 12th International Conference on Computing for Sustainable Global Development (INDIACom), 2025

MAIN CONTRIBUTION:
Proposes a smart, scalable framework for early detection and prevention of forest fires using UAV swarms with a spiral coverage algorithm, integrated with Vision-Language Models (VLMs) for intelligent image analysis, and equipped with fire-extinguishing capabilities for immediate preventive response.

KEY INNOVATIONS:
1. Integrated four-layer architecture combining sensing (UAV swarm), fog computing, cloud storage, and application services
2. Spiral coverage algorithm for systematic and efficient monitoring of large forest areas
3. Vision-Language Model (VLM) integration for semantic scene understanding beyond visual pattern recognition
4. Proactive fire prevention mechanism: UAVs equipped with fire-extinguishing agents for immediate response
5. Adaptive monitoring: system adjusts coverage frequency based on environmental conditions (temperature, wind, risk level)
6. Cost-effective alternative to traditional IoT-based forest monitoring systems

SYSTEM ARCHITECTURE (4 LAYERS):

1. SENSING LAYER:
- Swarm of UAVs equipped with sensors (smoke, CO2, temperature) and cameras (RGB + thermal)
- Continuous environmental monitoring with flexible deployment
- Dynamic coverage density adjustment based on environmental conditions
- Advantages: large area coverage, accessibility to remote/difficult terrain, balanced coverage, minimized monitoring gaps

2. FOG LAYER:
- UAV ground station serving as fog computing node
- Near-source data processing for reduced latency and real-time decision-making
- VLM-based image analysis via APIs to detect early fire signs (smoke, flames, abnormal environmental events)
- Swarm management: scheduling, flight path coordination, coverage area assignment
- Energy and bandwidth optimization through local processing

3. CLOUD LAYER:
- Main storage for permanent data archival
- High computation power for deep analysis and model training
- Historical database creation for ML model development and tuning
- Fire pattern and behavior analysis for continuous system improvement
- Enables long-term learning and adaptation to different environmental conditions

4. APPLICATION LAYER:
- End-user interface for multiple stakeholders: forest protection agencies, drone operators, emergency teams
- Crowdsourcing services: allows users/volunteers to report potential fires via mobile app
- Data integration from multiple sources (IoT, drones, crowdsourcing) for enhanced detection accuracy
- Real-time monitoring dashboard for decision-makers

SPIRAL COVERAGE ALGORITHM:

CONCEPT:
- Systematic monitoring ensuring comprehensive coverage without gaps
- Each UAV assigned a center point in the monitoring area
- UAV moves in expanding circular spiral path from inside out
- Gradual radius expansion after each rotation until entire zone covered

ALGORITHM PSEUDOCODE:
Input: a (initial radius), b (expansion rate), θ_max (max angle), Δθ (angle increment)
Output: Sequence of UAV positions (x, y)

1. Initialize θ = 0
2. while θ ≤ θ_max:
3.   r = a + bθ
4.   x = r × cos(θ)
5.   y = r × sin(θ)
6.   Move UAV to position (x, y)
7.   Capture image/data at current position
8.   θ = θ + Δθ
9. end while

ADVANTAGES:
- No coverage gaps
- Regular reassessment of same areas
- Energy efficiency through optimized path planning
- Elimination of UAV interference through coordinated movements
- Scalable with UAV swarm size

ADAPTIVE MECHANISM:
System adjusts based on environmental conditions:
- Coverage speed modification based on temperature and wind
- Number of active UAVs scaled according to risk level
- Increased monitoring frequency during high-risk conditions (high temperature, dry conditions)
- Cost reduction and efficiency improvement through dynamic resource allocation

VLM-BASED FIRE DETECTION:

CAPABILITY:
- Semantic scene understanding beyond visual patterns
- Pre-trained on massive datasets for robust generalization
- Real-time analysis of aerial images for early fire indicators

DETECTION TARGETS:
- Light smoke (not visible to naked eye)
- Vegetation discoloration
- Abnormal thermal hotspots
- Initial formation of small flames
- Presence of fire in vicinity

ADVANTAGES OVER TRADITIONAL CV:
- Understanding context and meaning, not just visual patterns
- Better handling of ambiguous cases (sunset colors, red skies vs. actual fire)
- Robust to visual variations and misleading patterns
- Pre-trained knowledge enables zero-shot or few-shot detection

PREVENTIVE RESPONSE MECHANISM:

PROCESS:
1. VLM detects hazard indicators in captured images
2. Location is precisely identified and logged
3. Fast-response UAV is dispatched to detected location
4. UAV sprays fire-retardant foam over hotspot
5. Prevents fire spread before full ignition occurs

KEY FEATURE:
Shifts from reactive (post-ignition response) to proactive (pre-ignition prevention) approach, significantly reducing potential damage and environmental impact.

EXPERIMENTAL VALIDATION:

DATASET: Fire-Detection-Image-Dataset-master
- Contains actual fire scenes and misleading images (sunsets, red skies)
- Tests model's ability to distinguish true fires from visual confusers

MODEL: GPT-5.3-based Vision-Language Model (API access)
- Binary classification task (fire presence/absence)

RESULTS:
- Fire detection accuracy: >99%
- Successfully distinguished real fires from natural scenes (sunset, red skies)
- Demonstrated robustness to visual confusion
- Validated VLM capability for fire detection in real-world scenarios

8. Integration of multiple data sources (sensors, cameras, crowdsourcing)
